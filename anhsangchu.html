Cảnh báo Lỗi 403 (Lỗi API)

Nếu bạn đang chạy file này trên máy tính cá nhân, bạn cần chèn **API Key của Gemini** vào đoạn code JavaScript (biến `API_KEY`) để ứng dụng hoạt động. Lỗi 403 là do thiếu/sai key.
